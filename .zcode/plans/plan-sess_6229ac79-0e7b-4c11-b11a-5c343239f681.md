# 墨水屏个人仪表盘改造方案（单屏版）

一屏看全：**天气 + 待办（复用 einktodo 原程序）+ AI 用量 + GitHub + 名言**，不做轮播不做切页，数据有变化才刷屏。

## 一、屏幕排版（800×480 黑白红三色）

- 红色专用于：高温、未读通知、已完成删除线、名言引号（待办位图本身是黑白的，嵌在右栏）
- 中文字体用工程里已有的 u8g2 文泉驿字库（wqy12 正文 + wqy16 标题）
- 天气图标用 GFX 基元手绘（太阳/云/雨/雪/雷）
- 分页绘制沿用现有 `display.nextPage()` 模式

## 二、待办复用方式（核心改动点）

完全复用 `todoList.h` 现有链路，只改两处：
1. **请求尺寸**：原代码本来就传 `?width=&height=`（现在是整屏 800×480），改为传右栏面板尺寸（约 370×350），einktodo 服务器会按这个尺寸渲染半屏待办图
2. **绘制位置**：下载-缓存（LittleFS）-If-Modified-Since 条件请求机制原样保留，画位图时加 X/Y 偏移落到右栏区域

待办的 API Key / API URL 仍走原来的 WiFiManager 配网页填写，管理习惯不变。

## 三、其它数据源

| 模块 | 来源 | 说明 |
|---|---|---|
| 天气 | Open-Meteo API | **免费、无需 key**；设置页填城市名，经 geocoding 接口转经纬度 |
| AI 用量 | 通用可配置接口 | 设置页填 URL + Bearer Key + JSON 数字路径（如 `data.percent`），画成红色进度条。预置 OpenAI 平台组织用量接口说明（需 Admin Key）。**Codex/ChatGPT 消费版用量官方无公开 API**，可用自建脚本/代理返回 JSON 接入；不配置则隐藏该栏 |
| GitHub | REST API | 填用户名：粉丝数、公开仓库、今日提交；填 Token（可选）额外显示未读通知数（红色） |
| 名言 | 本地（LittleFS 文本） | 手机网页编辑，一行一条，每次刷新随机轮换 |

## 四、文件改动

**新增**（`src/`）：
- `dashboard.h` — 排版渲染总入口
- `weather.h` / `github.h` / `aiUsage.h` — 三个数据模块（ArduinoJson 解析）
- `quotes.h` — 本地名言（LittleFS 持久化）
- `webui.h` — 常驻 Web 管理页（中文、手机友好）：`/` 状态+立即刷新、`/quotes` 名言编辑、`/settings` 城市/GitHub/用量配置
- `settingsExt.h` — 新设置结构存 EEPROM（独立偏移+magic，不破坏原数据）

**修改**：
- `main.cpp` — 新主流程：连 WiFi → 起 Web 服务 → 全量拉取渲染；loop 定期刷新（天气 30 分钟 / 待办每 5 分钟查 If-Modified-Since / GitHub 15 分钟 / 用量 30 分钟），**任一数据有变化才刷屏**
- `todoList.h` — 不直接改文件内容，在 dashboard 模式下以参数化尺寸调用（若需要小改则只改请求尺寸和绘制偏移两处）
- `platformio.ini` — ① `esp32` 环境加 `board_build.partitions = huge_app.csv`（app 空间 1.25MB→3MB，装中文字库，当前已占 83.3%）；② 加 ArduinoJson 依赖；③ 新增 `esp32_classic` 环境保留原版整屏行为（原逻辑随时可切回）

**不改**：`config.h`、`display.h`、`button.h`、`store.h`、`network.h`、`clock.h`、`led.h`。

## 五、交互

- **单击按钮**：立即全量刷新（原功能不变）
- **长按按钮**：进 WiFi 配网（原功能不变）
- 双击保持空闲（本轮不用）
- LED：后台拉数据时闪烁
- 日常管理：手机访问设备 IP（状态页有链接）

## 六、HTTPS 证书

内置 GTS Root R1（已有）+ ISRG Root X1（Open-Meteo）+ DigiCert Global Root（GitHub），握手失败自动降级 `setInsecure()` 重试一次（代码中注明取舍）。

## 七、验证与烧录

1. 本机 `pio run -e esp32` 编译验证（无需设备）
2. 你插上 ESP32 → 我执行上传（或你 VSCode 点上传）
3. 首次：长按 → 连热点 `E-ink Todo List AP`（密码 einktodo.com）→ 填 WiFi + einktodo Key → 再访问设备 IP 填城市/GitHub/用量

## 八、已知限制（如实说明）

- 三色墨水屏整屏刷新约 20–25 秒且有寿命次数限制 → 已按「有变化才刷」设计
- Codex 消费版用量无官方 API，该栏默认隐藏，配置自定义接口后启用
- 今日提交按 GitHub 公开 events 统计，仅覆盖公开事件
