# 墨水盆景 Windows 客户端

运行 `InkGarden.exe` 后，默认连接 `http://einktodo.local`。如果局域网不支持 mDNS，在右上角填写墨水屏显示的 IP，例如 `http://192.168.68.153`。

软件支持：

- 查看三项日课、连续天数、成长值和植物阶段；
- 点击“浇水”完成当天打卡；
- 读取、编辑并保存名言库；
- 保存最近一次设备地址。

电脑和墨水屏必须连接同一个局域网。源码不包含设备密码或 API Key。

重新编译时，在 PowerShell 中进入本目录后运行：

```powershell
.\build.ps1
```
